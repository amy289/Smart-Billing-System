# Amyy Smart Billing System — Lab 5

Browser-based billing application for Web Technologies Lab 5.

## Features
- Products stored as JavaScript objects in a cart array
- Add/remove multiple line items
- Quantity and stock validation
- Dynamic subtotal, discount, tax and grand total
- Invoice number and date
- Print-friendly invoice
- Invoice history stored in browser localStorage
- Responsive design

## Structure
- `index.html` — billing interface
- `css/style.css` — styling and responsive layout
- `js/app.js` — application logic

## Run
Extract the ZIP and open `index.html` in a browser. For XAMPP, place the folder in `htdocs` and visit:
`http://localhost/Lab5_Amyy_Smart_Billing_System/`

Note: This is a frontend learning project. It does not use a backend or database.
